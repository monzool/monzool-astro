**JUST LEANED THE** obvious today. [Screen](http://www.gnu.org/software/screen/) does null modem connections too.

At work I've been struggling with [minicom](http://alioth.debian.org/projects/minicom/). One thing that especially annoys me, it that it clears all text history when minimizing or resizing the VMware window. When I finally had had enough and googled for a replacement, I stumbled upon this blog entry [using-gnu-screen-as-terminal-emulator](http://unixsadm.blogspot.com/2008/01/using-gnu-screen-as-terminal-emulator.html) .

Doh!. Should have known. Of course it does. Screen rocks!
